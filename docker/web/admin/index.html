Yönetim (Docker kurulumu)

Bu kurulum Internet-in-a-Box yerine Docker ile çalışıyor, bu yüzden içerikler web panelinden değil sunucudaki komutlarla yönetilir. Komutları repo klasöründe çalıştırın.

Kütüphane (Kiwix ZIM dosyaları)

Listeyi config/content.conf dosyasında düzenleyin, sonra:

docker compose run --rm downloader zims

Yarıda kalırsa aynı komutu tekrar çalıştırın, kaldığı yerden devam eder. Yeni kitaplar birkaç saniye içinde kütüphanede görünür.

Türkçe belgeler (PDF)

AFAD, Sağlık Bakanlığı ve Hesperian gibi kaynakların Türkçe rehberleri config/docs.conf dosyasında listelenir. Tüm belgeler

docker compose run --rm downloader docs

Haritalar

Bölgeleri config/maps.conf dosyasında seçin. İndirmeden önce boyutları görmek için:

docker compose run --rm downloader maps-size
docker compose run --rm downloader maps

Kolibri

Kolibri ilk açılışta kurulum sihirbazını gösterir. Kanalları (dersleri) Kolibri'nin kendi Cihaz → Kanallar menüsünden içe aktarın.

Servisler

docker compose ps
docker compose logs -f
docker compose pull && docker compose up -d --build
